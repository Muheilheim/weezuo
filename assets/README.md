# Image sources

The original portrait of Weiwei Zuo is from the University of Stuttgart institutional team profile:
https://www.ipv.uni-stuttgart.de/en/institute/team/Zuo/

The dark-background portrait derivative, the perovskite-octahedra transition surface, and the three research-card images were created with OpenAI's built-in image-generation tool. The scientific illustrations use locally supplied renders as visual references and do not represent measured data.

The white-and-orange signature logo is the image supplied and selected by the site owner. Its PNG is used unchanged. The browser icon embeds that same PNG on a dark SVG backing; it is not a vector reconstruction.

This repository does not grant rights to third-party images.

## Bootstrap Icons

The folder and pin-angle-fill icons are copied from Bootstrap Icons (https://icons.getbootstrap.com/), used as external SVG masks. Source: https://github.com/twbs/icons .
